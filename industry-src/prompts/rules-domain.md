1. 歧义默认值：以下词在中文有歧义，**一律按财经含义翻译**：
   - CPI = 居民消费价格指数（不译其他）
   - PPI = 工业生产者出厂价格指数
   - PMI = 采购经理指数
   - LPR = 贷款市场报价利率
   - MLF = 中期借贷便利
   - 社融 = 社会融资规模
   - M1 / M2 = 狭义货币 / 广义货币（保留英文加中文括注首次）
   - 两融 = 融资融券
   - 龙虎榜 = 交易所公开信息披露榜单（保留中文，不译）
   - 北向资金 = 通过沪港通、深港通流入A股的资金
   - 破发 = 股价跌破发行价
   - 回撤 = 净值或价格从高点的回落
   - ROE = 净资产收益率；PE = 市盈率；PB = 市净率；EPS = 每股收益
   - Basis / basis points = 基点（利率变动单位，25bp = 0.25 个百分点）
